## Featured projects

### TDI-APS: Kenya Procurement Intelligence
Production-grade procurement intelligence platform built across six structured sprints.

- **Stack:** FastAPI, PostgreSQL with row-level security
- **Features:** Compliance engine, scoring, PDF generation, full CI/CD

### Pharmacy POS
Complete point-of-sale system for pharmacies, built for real-world use.

- **Stack:** Node/Express, React/Vite, MySQL

### Hali: Flood Intelligence for Kenya
Flood intelligence platform that started at the 2026 AI × City Climate Action Hackathon at Innovate4Cities, in response to Kenya's 2026 flooding crisis.

### KarbonTrack (EPRA CarbonTrack)
Transport emission intelligence platform supporting Kenya's NDC 3.0 compliance, built for the EPRA Hackathon 2026.

- **Stack:** React, Vite, Groq
- **Features:** Role-based access and a validated Excel data intake pipeline

### ClearPath Credit
Explainable AI credit scoring for women farmers, delivered over USSD. Built for the Kenya AI Challenge with Mercy Corps AgriFin (eSusFarm) and shortlisted for the in-person sprint.

- **Features:** Neo4j and RAG prototype, pitch deck and solution description

### APEX: AI Pitch Coach
Flutter app that coaches founders on their pitches, built across seven sprints.

- **Stack:** Flutter, Groq API, Supabase
- **Features:** Voice speech-to-text, six-dimension scoring, Stripe and Paystack payments

### LEGO Stack
Rust-based composable code-generation CLI, my "factory" for building other systems faster. Includes reusable bricks such as `whatsapp_lego`, `bi_lego` and `rag_lego`, plus CI/CD packages for Python/FastAPI and Node/React projects.

### Synthex
Built for the AMD x LabLab.ai hackathon.

### CARWASH SaaS Platform
Multi-tenant backend that handles payments, SMS notifications and real-time booking management.

- **Payments:** M-Pesa integration
- **Notifications:** Africa's Talking SMS
- **Stack:** Django REST, PostgreSQL, Redis, Docker
- **Deployment:** Microservices behind a load balancer

### More builds

- **Flutter AI Chat Template:** multi-provider chat app (xAI, OpenAI, OpenRouter, Groq), available on Gumroad
- **Satellite disaster detection pipeline:** SAR and optical imagery
- **Microservices Architecture Demo:** Flutter frontend connected to multiple Django services behind an API gateway
- **CodeGuard (in progress):** uses AI to test edge cases within a codebase. [Open CodeGuard](https://codeguard-ten.vercel.app/)
